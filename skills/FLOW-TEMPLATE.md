# Assignment Flow — 작성 가이드

이 파일은 참고용입니다. **수정하지 마세요**. 실제 작성은 `flow.md`에서 하세요.

---

## 🎯 flow.md 작성 방식: 줄글(prose) 권장

flow.md는 **자유로운 줄글**로 작성하세요. 구조적 템플릿을 채우는 방식이 아니라, 과제/논문의 방향을 **에세이처럼** 서술하세요.

5축 평가 시스템이 자동으로:
- 당신의 줄글에서 **RQ / Thesis / 주요 주장**을 추출
- 각 문장을 분석하여 **레퍼런스가 필요한 주장**을 식별
- 각 주장에 대해 **Consensus 검색 키워드**를 자동 생성
- 5축(레퍼런스 충실도, 논리 전개, 반박 논리, 독창성, 구성개념 정의)으로 평가

---

## 📝 flow.md에 꼭 담아야 할 내용

줄글로 쓰되, 다음 요소들이 자연스럽게 녹아 있어야 합니다:

### 1. 메타데이터 (파일 최상단에 간단히)
```
과제명: [제목]
코스: [과목명]
마감: YYYY-MM-DD
분량: [단어 수]
인용 스타일: APA / MLA / Chicago 등
```

### 2. 핵심 앵커
다음 두 가지는 줄글 중에 **반드시 한 문장씩 명시**하세요:
- **연구 질문 (RQ)**: 이 글이 답하려는 질문
- **핵심 주장 (Thesis)**: 그 질문에 대한 당신의 답

### 3. 논증 흐름 (줄글로)
다음 질문에 답하는 방식으로 자유롭게 서술:
- **문제 설정**: 왜 이 주제가 중요하고 어떤 논쟁이 있는가?
- **기존 관점 비판**: 기존 문헌의 한계는 무엇인가?
- **자신의 제안**: 당신은 어떤 새로운 프레임워크/관점/분석을 제시하는가?
- **근거와 반론**: 어떤 증거로 뒷받침할 것이며, 예상 반론은 어떻게 다룰 것인가?
- **함의**: 이 논증이 성립한다면 분야에 무엇을 기여하는가?

### 4. 선택: 섹션 스케치
글의 흐름을 섹션으로 예상하고 있다면, 줄글 중간에 "나는 Section 1에서 ~을 다루고, Section 2에서 ~을 논한다" 식으로 녹여 쓰거나, 줄글 뒤에 짧은 목차를 덧붙여도 됩니다.

## 🚫 하지 말아야 할 것

- 체크박스 목표 리스트로 쪼개기 (자유로운 서술로 대체)
- 템플릿 빈칸 채우듯 작성
- "[논문 이름 미정]" 같은 placeholder (실제 논문은 5축 평가 후 Consensus로 자동 검색)

---

## 📋 작성 후 흐름

1. `flow.md` 작성 완료 → **"평가해줘"** 입력
2. 시스템이 자동으로:
   - 문장 단위 주장 추출 (claim-extractor)
   - 5축 냉정 평가 (evaluation-orchestrator가 axis1~6 scorer 병렬 디스패치 → aggregator 집계)
   - `evaluation.md` + `work-plan.md` 생성
3. `work-plan.md` 확인 후 **"작업 시작해줘"** 입력
4. 시스템이 work-plan.md의 HUNT 과제 목록을 따라 Consensus 자동 검색

## 💡 예시 (짧은 prose flow)

> 과제명: EF 재개념화 에세이
> 코스: Cognitive Development Essay Assignment (CDEA)
> 마감: 2026-05-20
> 분량: 2500–3000 words
> 인용 스타일: APA
>
> 이 에세이는 Kroupin et al. (2025)이 최근 PNAS에서 제기한 주장 — EF는 "보편적 역량"이거나 "문화특수적 스킬셋" 중 하나로 선택해야 한다는 이분법 — 에 대한 비판적 평가를 시도한다. **나의 연구 질문은 이 이분법이 타당한가, 그리고 EF를 어떻게 더 나은 방식으로 재개념화할 수 있는가이다.** **핵심 주장은 다음과 같다: EF를 보편/특수의 이분법으로 강제 선택하는 대신, '규칙의 속성(자발성 × 임의성)'에 기반한 네 가지 영역으로 재개념화함으로써 문화적 특수성을 포괄하면서도 보편적 EF의 가능성을 보존할 수 있다.**
>
> Section 1에서는 EF가 전통적으로 보편적 인지 역량으로 다뤄져 온 배경과 Kroupin의 문제 제기를 정리한다. Section 2에서는 보편성/특수성 논쟁의 핵심 쟁점인 impurity problem을 상세히 다룬다 — 문화 간 EF 점수 차이가 EF 자체의 차이인지, 아니면 측정 과정에 혼입된 문화특수 요소의 차이인지 구분하기 어렵다는 점이다. ... [계속]
