# Research Gap — 작성 가이드

이 파일은 참고용입니다. **수정하지 마세요**. 실제 작성은 `research-gap/research-gap.md`에서 하세요.

---

## 🎯 research-gap 단계의 위치

flow.md를 본격적으로 쓰기 *전* 단계. 아직 thesis가 단단히 형성되지 않았을 때, **분야의 anchor 논문들이 어디 있고 어디에 갭이 있는지** 먼저 보는 단계.

```
[research-gap]  →  [flow]  →  [output]  →  [final]
   ↑ 지금 여기
```

이미 thesis가 명확하면 이 단계 건너뛰고 바로 flow.md로 가도 됩니다 (opt-in).

---

## 🎯 research-gap.md 작성 방식: 줄글(prose) 권장

flow.md와 마찬가지로 **자유로운 줄글**로 작성하세요. 시스템이 알아서:

- 줄글에서 **가설 H-NN** 단위로 분해
- 각 H에 대해 **어떤 종류의 anchor 논문**을 찾아야 할지 판단
- Consensus 검색 쿼리·기대 논문 프로필 생성
- 검색 결과를 분야별로 정리 → PDF 다운로드 후 갭 frame으로 분석 → 통합 갭 리포트

---

## 📝 research-gap.md에 꼭 담아야 할 내용

줄글로 쓰되, 다음 4요소가 자연스럽게 녹아 있어야 합니다.

### 1. 메타데이터 (파일 최상단에 간단히)

```
주제명: [가제]
필드: [예: Cognitive Development, Educational Psychology]
잠정 마감: YYYY-MM-DD (있다면)
```

### 2. 문제의식

어떤 영역이 궁금한가? 왜 이 영역을 들여다보려고 하는가? (분야 내 논쟁·미해결 질문·관찰된 현상 등)

### 3. 주장하고 싶은 것 (잠정 — provisional thesis)

지금 시점에서 본인이 잠정적으로 주장하고 싶은 것. 거칠어도 OK. 한 문단 정도면 충분.

> 예: "EF는 보편적이거나 문화특수적이거나 둘 중 하나라는 이분법 대신, 규칙의 속성(자발성·임의성)에 따른 4가지 영역으로 재개념화할 수 있다고 본다."

### 4. 확인하고 싶은 것 (선행 연구에 묻고 싶은 것)

- 이 주장과 관련해 이미 누가 무엇을 했는가?
- 어떤 frame·방법론으로 다뤘는가?
- 어떤 anchor가 표준으로 자리잡았는가?
- 비슷한 시도가 있었다면 한계는 무엇이었는가?

가설 형태로 H-01, H-02… 식으로 나열해도 좋고, 줄글 중간에 자연스럽게 녹여도 좋습니다.

### 5. 본인의 가정·전제

현 시점에서 본인이 깔고 있는 전제. 분석 단계에서 이게 정당화되는지 점검하기 위해 명시해 둡니다.

> 예: "보편적 EF가 *개념적으로* 존재한다고 가정한다. 다만 측정의 임의 규칙 의존성 때문에 직접 측정이 어렵다고 본다."

## 🚫 하지 말아야 할 것

- **체크박스 목표 리스트로 쪼개기** — 자유 줄글로 대체
- **"[anchor 논문 미정]" 같은 placeholder** — anchor는 시스템이 검색해서 찾아옵니다
- **flow.md 수준의 정밀한 논증 구조** — 그건 다음 단계. 이 단계는 *영역 탐색*

---

## 📋 작성 후 흐름

1. `research-gap.md` 작성 완료 → **"리서치 갭 분석해줘"** 입력
2. 시스템이:
   - 줄글에서 가설 H-NN 단위로 분해
   - 각 H에 대한 anchor 검색 계획 작성 → `research-plan.md` 생성
3. `research-plan.md` 확인 후 **"리서치 진행해줘"** 입력
4. 시스템이 Consensus 4-stage 파이프라인으로 anchor 검색 → `papers/search-results/research-gap.md`
5. 사용자가 결과 보고 PDF 다운로드 → `papers/candidates/research-gap/` 에 떨어뜨림
6. **"논문 처리해줘"** → 갭 frame으로 분석 → `papers/analyzed/research-gap/[R][D].*.md`
7. **"갭 리포트 만들어줘"** → 통합 갭 리포트 → `research-gap/gap-report.md`
8. 갭 리포트 보고 본인 thesis 다듬기 → `flow/flow.md` 작성 시작

## 💡 예시 (짧은 prose research-gap.md)

> 주제명: EF 재개념화 (Cognitive Development Essay)
> 필드: Cognitive Development
>
> 최근 EF가 보편 인지 역량인지 문화특수적 스킬인지에 대한 논쟁이 활발하다 (Kroupin et al. 2025). 나는 이 이분법이 성급하다고 보고, EF를 *규칙의 속성*에 따라 재개념화하고 싶다.
>
> 잠정적 주장은 다음과 같다: 규칙의 자발성(외부 부과 vs 자기 선택)과 임의성(임의 vs 고정) 두 축에 따라 EF를 4가지 영역으로 나누면, 보편/특수 이분법이 해소되고 다양한 사회의 EF를 일관되게 다룰 수 있다.
>
> 이 주장을 점검하려면 다음을 확인해야 한다.
>
> H-01. **EF의 보편성/특수성 논쟁의 현주소** — 누가 어떤 입장에서 무엇을 발견했고, 표준 anchor는 어떤 논문들인가? Kroupin 외에 핵심 reviewer는?
>
> H-02. **EF impurity problem** — EF 측정에 포함되는 비-EF 요인들이 어떻게 분리되는가? Latent variable approach의 한계 anchor는?
>
> H-03. **Hot/Cool EF 구분과 그 한계** — Hot/Cool 이분법은 어떻게 형성됐고, 어떤 경계 사례가 있는가?
>
> H-04. **자발성·임의성 차원의 선행 연구** — 자기결정 이론, pretend play, 양심 형성 등에서 자발성/임의성이 어떻게 다뤄졌는가?
>
> H-05. **횡문화 EF 연구의 sampling 한계** — 비-WEIRD 표본은 얼마나 있고, 어떤 종속변수·과제가 사용됐는가?
>
> 본인의 가정: 보편적 EF가 *개념적으로* 존재하나 직접 측정이 어렵다는 것. 그리고 규칙의 깊이(자발성·고정성·반복성의 결과)가 EF 수행에 영향을 준다는 것.

위와 같이 자연스러운 에세이 문체로 작성하면 시스템이 H-NN 단위로 분해해서 anchor 검색 계획을 짜줍니다.
